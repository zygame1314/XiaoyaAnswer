# 📘 小雅答答答 - 学习小助手 📘

## 🚀 主要功能

1. **快速解答** 📝 - 获取参考答案，帮助理解题目。
2. **自动填写** ✨ - 一键填写答案，支持抽题考试。
3. **编辑答案** 🖋️ - 查看、修改已获取的答案。
4. **导出作业** 📄 - 导出为 Word (.docx) 或 Markdown (.md)。

## 🛠️ 支持题型

- 单选题、多选题
- 填空题、判断题
- 简答题、排序题
- 匹配题、编程题等

## ⌨️ 快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl + Shift + A | 获取参考答案 |
| Ctrl + Shift + F | 自动填写答案 |
| Ctrl + Shift + E | 查看/编辑答案 |
| Ctrl + Shift + Q | 导出作业 (Word) |
| Ctrl + Shift + M | 导出作业 (Markdown) |

## 📖 使用须知

- 登录后进入作业/测验的**答题页**，再点击“获取答案”或“填写答案”。
- 页面上找不到菜单时，刷新页面；菜单标题旁会显示当前脚本版本。

## 🧰 常见问题

- **提示“当前页面未识别为作业/测验页”**：确认地址栏包含 `resource` 或 `course_paper`，刷新后重试；iframe 页面请在新标签页直接打开。
- **提示 401 / Unauthorized**：通常是同时登录了多个学校。退出其他学校，只保留当前学校的登录状态后刷新。
- **抽题考试**：脚本会自动识别抽中的题目，只填写抽中的题，不会把整卷题目混在一起。
- **账号安全**：不要在不同小雅账号之间混用激活码；提示“账号不一致”时，请登录激活时绑定的账号。
- **更新脚本**：在脚本管理器中用本地 `小雅答答答.user.js` 完整覆盖旧内容，不要使用 `@require file://`。
- **开发调试**：可使用 ScriptCat 官方 VSCode 扩展，详见 [官方文档](https://docs.scriptcat.org/docs/use/vscode/)。
